# CompraMás — Web Oficial

Sitio web oficial, documentación y páginas legales de **CompraMás**, desarrollado por **Arandu Labs LLC**.

🌐 **Dominio oficial:** [compramas.arandulabs.dev](https://compramas.arandulabs.dev)  
🏢 **Desarrollador:** [Arandu Labs LLC](https://arandulabs.dev)

---

## 📑 Estructura de Páginas

- **`index.html`** — Landing page principal interactiva con presentación de funcionalidades, comparador de supermercados, escáner nutricional, mapa de combustibles, optimizador de changuito y enlaces de descarga.
- **`faq.html`** — Preguntas frecuentes sobre funcionamiento, fuentes de datos, escaneo de códigos de barra, geolocalización y privacidad.
- **`privacy.html`** — Política de privacidad oficial para la aplicación móvil CompraMás.
- **`terms.html`** — Términos y condiciones de uso del servicio.
- **`delete-account/index.html`** — Procedimiento y formulario para la solicitud de eliminación de cuenta y purga de datos conforme a las directrices de Google Play.

---

## 🛠️ Stack Tecnológico

- **HTML5 & CSS3**
- **Tailwind CSS** vía CDN
- **Google Fonts** (*Inter* y *Outfit*)
- **Glassmorphism & Obsidian Dark Theme** siguiendo el sistema de diseño corporativo de Arandu Labs.
